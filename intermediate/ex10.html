Intermediate · Exercise 10

Responsive layout

A two-column Grid is useful when space allows. At the small-screen breakpoint in the shared stylesheet, it becomes one column so neither region is squeezed.

Live result

Resize the viewport to test the column change

Main story

The main content receives more room on wide screens and naturally fills the row on narrow screens.

Side note

Supporting content stays beside the story only while there is space.

Solution markup

<div class="ex10-layout">
  <section aria-labelledby="story-title">
    <h3 id="story-title">Main story</h3>
    <p>The main content receives more room.</p>
  </section>
  <aside aria-labelledby="note-title">
    <h3 id="note-title">Side note</h3>
    <p>Supporting content sits beside the story.</p>
  </aside>
</div>
